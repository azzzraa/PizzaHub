# PizzaHub

Full-stack pizza ordering application built with:

- React
- Express.js
- PostgreSQL
- Prisma
- JWT Authentication

## Features

- User registration
- Secure login
- Password hashing with bcrypt
- JWT authentication
- Pizza menu
- Shopping cart

## Tech Stack

Frontend:
- React
- Vite

Backend:
- Express.js
- Prisma

Database:
- PostgreSQL
